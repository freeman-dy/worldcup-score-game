# 월드컵 스코어 맞추기 웹앱 v2 - 친구 직접 접속형

## 개념
이 버전은 친구들이 각자 휴대폰에서 링크로 접속해 직접 예상 스코어를 입력하는 서버형 웹앱입니다.

## 주요 기능
- 1차전: 2026.06.12 11:00 체코 vs 대한민국
- 2차전: 2026.06.19 10:00 대한민국 vs 멕시코
- 3차전: 2026.06.25 10:00 대한민국 vs 남아공
- 친구들이 직접 이름/예상스코어 입력
- 같은 이름으로 다시 입력하면 수정
- 전체 참가자 예상 현황 공개
- 관리자 비밀번호로 결과 확정
- 정확한 스코어 적중자 자동 계산
- 적중자 여러 명이면 균등분배
- 적중자 없으면 다음 경기 이월
- 관리자명/통장번호/참가비 수정 가능
- SQLite 데이터베이스 저장

## 설치 방법

### 1. Node.js 설치
Node.js LTS 버전을 설치합니다.

### 2. 압축 해제 후 폴더 열기

### 3. .env.example 파일을 복사해서 .env 만들기
.env.example → .env

### 4. 관리자 비밀번호 변경
.env 파일에서 아래 값을 원하는 비밀번호로 바꿉니다.

ADMIN_PASSWORD=1234

### 5. 패키지 설치
터미널에서 실행:

npm install

### 6. 실행
npm start

### 7. 접속
본인 PC에서는 아래 주소로 접속:

http://localhost:3000

## 친구들이 접속하게 하는 방법

### 방법 A. 같은 와이파이 안에서 테스트
1. 실행 중인 PC의 내부 IP를 확인합니다.
2. 예: 192.168.0.15
3. 친구 휴대폰에서 아래처럼 접속합니다.
   http://192.168.0.15:3000

단, 같은 와이파이에 있어야 합니다.

### 방법 B. 인터넷 공개 배포
Render, Railway, Fly.io, Vercel 서버리스가 아닌 Node 서버 배포가 가능한 곳에 올립니다.

추천:
- Render
- Railway
